
# Gerador de Assinaturas Agro

Aplicação web desenvolvida para criar assinaturas de e-mail personalizadas a partir dos dados profissionais do usuário.

O sistema permite preencher as informações, selecionar o estado e a unidade e gerar uma assinatura em formato PNG para download.

## Funcionalidades

- Preenchimento de nome, cargo e telefone
- Seleção de estado e unidade
- Atualização dinâmica das unidades conforme o estado selecionado
- Geração de assinaturas personalizadas
- Download da assinatura em PNG

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API

## Como utilizar

1. Acesse a aplicação pelo navegador.
2. Preencha os dados profissionais.
3. Selecione o estado e a unidade.
4. Gere a assinatura.
5. Faça o download da imagem gerada.

## Melhorias planejadas

- Validação e formatação de telefones
- Tratamento de textos longos
- Tratamento de erros no carregamento de imagens
- Melhorias na usabilidade do formulário
