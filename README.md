
# Gerador de Assinaturas Agro

Aplicação web desenvolvida para gerar assinaturas de e-mail personalizadas de forma simples e rápida.

O usuário pode preencher seus dados profissionais, selecionar o estado e a unidade e gerar uma assinatura em imagem PNG, pronta para download.

## 🚀 Funcionalidades

- Preenchimento de nome, cargo e telefone
- Seleção de estado e unidade
- Atualização dinâmica das unidades conforme o estado selecionado
- Geração de assinatura de e-mail personalizada
- Download da assinatura em formato PNG

## 🛠️ Tecnologias utilizadas

- HTML5 — Estrutura da aplicação
- CSS3 — Estilização e layout
- JavaScript — Lógica e interatividade
- Canvas API — Geração da imagem da assinatura

## 💻 Como utilizar

1. Abra a aplicação no navegador.
2. Preencha os dados profissionais.
3. Selecione o estado e a unidade.
4. Gere a assinatura.
5. Faça o download da imagem PNG.
