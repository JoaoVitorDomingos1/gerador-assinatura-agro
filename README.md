
# Gerador de Assinaturas Agro

Aplicação web desenvolvida para gerar assinaturas de e-mail personalizadas de forma simples e rápida.

O usuário pode preencher seus dados profissionais, selecionar o estado e a unidade e gerar uma assinatura em imagem PNG, pronta para download.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API
